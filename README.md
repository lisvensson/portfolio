# Li Svensson — Portfolio

Personal portfolio site built with Vite, React, TypeScript, and Tailwind CSS.

## Stack

- **Vite** + **React 19** + **TypeScript**
- **Tailwind CSS v3** with custom muted amber/warm palette and dark mode
- **react-scroll** for smooth section navigation
- **Heroicons** + **Font Awesome** for icons

## Features

- EN/SV language toggle with full translations
- Dark mode with system preference detection and localStorage persistence
- SVG mango mascot with floating animation, switches between light/dark variant
- Responsive layout with mobile hamburger menu
- Sections: Hero, About, Skills, Projects, Contact

## Dev

```bash
npm install
npm run dev
```
